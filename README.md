# Machine Learning Coursework

Projects from MATH482 at Boğaziçi University.

## Wind Power Prediction

A Kaggle course project on predicting wind power across seven wind farms.
We used chronological cross-validation and explored cross-farm imputation,
spatial neural networks, and probabilistic forecasts.

| Notebook | Contents |
| --- | --- |
| [Wind power modeling](ikinci%20notebook.ipynb) | Exploratory analysis, chronological validation, model experiments, and uncertainty estimation |
| [Exp04 blend](first%20notebook.ipynb) | Blend weight selection and code for reproducing the selected submission with the original experiment files |

The selected Kaggle submission blended 60% Spatial NN and 40% Cross-Farm NN
predictions. It scored **0.18592 public RMSE** and **0.17151 private RMSE**.
